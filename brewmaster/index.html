Every upgrade, on purpose.

brewmaster upgrades only what you tell it to, patch, minor, or major, and understands why a package exists on your machine before it touches it. No AI, no guessing, deterministic logic from real data.

Six things a bare "brew upgrade" doesn't stop to ask.

Understands why a package is there

Traces the dependency reasoning behind a package before you decide anything about it.

brewmaster why
2
Upgrades only what you choose

Patch, minor, or major, picked per run or locked into a named profile you can reuse.

--minor
3
Scores the risk before it acts

Dependents and bump size decide a score. Confirm on MEDIUM, skip HIGH outright unless told otherwise.

--check-deps
4
Never upgrades without a way back

A snapshot is taken automatically before every cleanup removal, restorable with one command.

snapshot restore
5
Finds what's just sitting there

Orphan, stale, and old-pinned packages, with the dependency reasoning behind each one.

brewmaster bloat

§Commands(8)
Every run defaults to a dry, read-only report unless told to act.
1
brewmaster --dry-run

See what would upgrade, at the default patch level, without touching anything.

2
brewmaster --minor

Upgrade minor bumps only.

3
brewmaster --check-deps

Score dependency risk before applying any upgrade.

4
brewmaster why <pkg>

Explain why a package is on this machine.

5
brewmaster snapshot save

Save the current package state, labelled for later.

6
brewmaster cleanup --dry-run

Read-only report of orphan and stale packages safe to remove.

7
brewmaster profile list

List named upgrade policies for this machine.

8
brewmaster log

Show upgrade, cleanup, and snapshot history.

Nothing changes here by accident.
